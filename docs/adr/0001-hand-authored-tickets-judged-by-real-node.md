# Hand-authored Tickets, judged by real Node

Each Shift's Tickets (kind, source line, parent Ticket, Receipt lines) are written by hand in the level file, not derived by instrumenting Node or by interpreting the JavaScript. CI runs the Shift's program on Node 24 many times and fails if any observed output is outside the level's Accepted outputs, or if the simulator's order from the Tickets isn't one of them. Accepted outputs are listed by hand too, not generated from observed runs: a rare order (a top-level timer beating setImmediate) may never show up in a CI run but is still correct. Hand-authoring is minutes per Shift at our scale; interpreting JS would mean building an interpreter, and instrumenting Node (async_hooks or patched scheduling APIs) is the upgrade once hand-authoring stops scaling.
